# پروژه اذان و اوقات شرعی - بازطراحی شده با .NET 10 و WPF

## معرفی
این پروژه یک برنامه کاربردی دسکتاپ برای نمایش اوقات شرعی شهرهای ایران است که با استفاده از جدیدترین تکنولوژی‌های مایکروسافت بازطراحی شده است.

## ویژگی‌ها

### ✨ ویژگی‌های اصلی
- **نمایش اوقات شرعی**: شامل اذان صبح، طلوع آفتاب، اذان ظهر، غروب آفتاب، اذان مغرب و نیمه شب شرعی
- **پشتیبانی از تمام شهرهای ایران**: ۳۰ شهر بزرگ ایران
- **تقویم چندگانه**: نمایش همزمان تاریخ شمسی، میلادی و قمری
- **رویدادهای تقویمی**: نمایش مناسبت‌های رسمی و مذهبی
- **اعلان اذان**: پخش صدای اذان در زمان‌های مشخص شده
- **رابط کاربری مدرن**: طراحی زیبا با تم رنگی جذاب و فونت فارسی

### 🎨 بهبودهای رابط کاربری
- استفاده از کارت‌های سایه‌دار برای جداسازی بخش‌ها
- رنگ‌بندی مدرن با پالت رنگی Material Design
- آیکون‌های ایموجی برای هر زمان نماز
- پشتیبانی کامل از راست‌چین (RTL)
- انیمیشن‌های نرم برای تعاملات

### 🔧 بهبودهای فنی
- **معماری MVVM**: جداسازی منطق کسب‌وکار از UI
- **وابستگی کم**: حذف کتابخانه‌های سنگین مانند MahApps.Metro
- **کد تمیز**: استفاده از Nullable Reference Types
- **عملکرد بهینه**: الگوریتم‌های محاسباتی کارآمد
- **قابل نگهداری**: ساختار ماژولار و مستندات کامل

## پیش‌نیازها

## نصب و اجرا

### روش اول: استفاده از خط فرمان

```bash
# رفتن به پوشه پروژه
cd /workspace/AdhanPrayerTimes.App

# بازیابی پکیج‌ها
dotnet restore

# کامپایل پروژه
dotnet build

# اجرای برنامه
dotnet run
```

### روش دوم: استفاده از Visual Studio

1. فایل `AdhanPrayerTimes.sln` را باز کنید
2. کلید `F5` را بزنید یا از منو `Debug > Start Debugging` را انتخاب کنید

### ساخت فایل اجرایی

```bash
# ساخت نسخه Release
dotnet publish -c Release -r win-x64 --self-contained true

# خروجی در پوشه bin/Release/net10.0-windows/win-x64/publish قرار می‌گیرد
```

## نحوه استفاده

1. **انتخاب شهر**: از لیست کشویی، شهر مورد نظر خود را انتخاب کنید
2. **مشاهده اوقات شرعی**: زمان‌های نماز به صورت خودکار نمایش داده می‌شوند
3. **تاریخ‌ها**: تاریخ شمسی، میلادی و قمری در بالای صفحه نمایش داده می‌شود
4. **رویدادها**: مناسبت‌های روز در بخش مربوطه نمایش داده می‌شود
5. **ذخیره تنظیمات**: با کلیک روی دکمه "ذخیره تنظیمات"، شهر انتخاب شده ذخیره می‌شود

## الگوریتم محاسبه اوقات شرعی

این پروژه از الگوریتم‌های نجومی استاندارد برای محاسبه اوقات شرعی استفاده می‌کند:

- **محاسبه زمان ظهر شرعی**: بر اساس طول جغرافیایی شهر
- **معادله زمان**: اصلاح اختلاف بین زمان خورشیدی و ساعت
- **انحراف خورشیدی**: محاسبه بر اساس روز سال
- **زاویه ساعتی**: برای محاسبه زمان طلوع و غروب

### فرمول‌های استفاده شده

```
زمان پایه = 12 + (طول جغرافیایی / 15)
معادله زمان = -7.6 × sin(0.0327 × روز_سال) - 9.9 × cos(0.0327 × روز_سال)
انحراف خورشیدی = 23.45 × sin(0.0172 × (روز_سال - 80))
```

## سفارشی‌سازی

### تغییر تم رنگی

در فایل `App.xaml` می‌توانید رنگ‌ها را تغییر دهید:

```xml

```

### افزودن شهر جدید

در فایل `Services/CityService.cs`:

```csharp
new("نام شهر", طول_جغرافیایی, عرض_جغرافیایی),
```

### تغییر صدای اذان

فایل صوتی خود را به پوشه `Resources` اضافه کرده و در `MainWindow.xaml.cs` بارگذاری کنید:

```csharp
_soundPlayer = new System.Media.SoundPlayer(Properties.Resources.Azan);
```
